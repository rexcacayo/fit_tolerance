# Fit Tolerance

> **Versión actual: 1.0.0** (Blender 4.2 – 5.x) → instalar `version_1.0.0/dist/fit_tolerance-1.0.0.zip`

Complemento de Blender para que **las piezas encajen a la primera**: agujeros y ejes compensados según el material, huecos para insertos de rosca en caliente y chaflán anti pata de elefante. Incluye una pieza de prueba para calibrar tu impresora y guarda la tabla de cada material.

Clic en la pared de un agujero o eje → detecta el diámetro, lo redondea a la medida nominal y lo compensa (apretado, deslizante u holgado). Copia nueva, original oculto.

## Familia de plugins

**Mesh Doctor → Print Scale → Thicken → Fit Tolerance → Base Support → BigPrint / MagSnap → Color Print Splitter**
